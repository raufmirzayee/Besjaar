OPTIONAL PRODUCT FIELDS
Create only the fields you need in Shopify. Existing products work without them.
Text values can be translated using your store's translation workflow.

Product metafields (multi-line text):
  custom.introduction       Introductory copy above the purchase form.
  custom.installation       Product-specific installation instructions.
  custom.care_instructions  Product-specific care/replacement guidance.

Product or variant metafields:
  custom.mpn                Single-line text. A real manufacturer part number.
  custom.price_valid_until  Date. A real future price-expiry date only.

Variant values take precedence for MPN and expiry. Unknown or expired expiry
values are omitted. A barcode is never substituted for an MPN. Existing barcode
fields remain the source of GTINs; a valid check digit does not verify ownership.

OPTIONAL POLICY SETTINGS
The new 'SEO policy details' theme settings are OFF by default.
They affect structured data only; they do not change checkout shipping charges.
- Set the actual country and currency covered by the policy.
- Set Standard shipping rate and Free shipping threshold in the existing settings.
- Enable Shipping rate verified only when one flat rate is accurate for the
  selected country/currency. Keep it disabled for weight/postcode-dependent rates.
- Enable Verified free-shipping threshold only if the threshold really applies.
- Enable Return terms verified only after checking the return window, mail return
  method and return-postage choice against the actual published policy.
- Other destinations receive no inferred policy. No delivery-time estimate is
  emitted by these schema settings. Broader market rules belong in verified
  store/Merchant Center policy data.
Optional schema warnings can remain when unknown policy fields are omitted.
